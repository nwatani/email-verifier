How this works

Browser checks

The tool validates syntax, normalizes the domain, checks mail routing through HTTPS DNS, and identifies common disposable and role-account patterns. It cannot directly prove that an individual mailbox exists from a static web page.

Deep verification

A compatible Reacher-style server can perform server-side SMTP/provider checks. That is the mode that can produce Safe/Risky/Invalid/Unknown mailbox-level results.

Privacy

Browser mode does not send the full address to a verification API. DNS lookups use only the domain. Deep mode sends the address to the verification service you configure.

Good practice

Treat browser-only results as an assessment, not proof of mailbox existence. Catch-all domains are inherently uncertain. Avoid repeatedly testing large lists against the same provider.
